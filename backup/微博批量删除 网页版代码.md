因为手机串号问题，登录微博发现是之前的人的，有点担心，遂想把微博全删了，但是没找到微博批量删除能力。
所以就只能自己写一个

```
function deleteMessage() {
  // 下箭头
  let iDom = document.getElementsByClassName('woo-font woo-font--angleDown morepop_action_bk3Fq')[0];
  if (iDom) {
    iDom.click();
    setTimeout(() => {
    // 删除点击
      document.getElementsByClassName('woo-box-flex woo-box-alignCenter woo-pop-item-main')[7].click();
    }, 1000)
    setTimeout(() => {
      // 确认删除框 确认点击
      document.getElementsByClassName('woo-button-main woo-button-flat woo-button-primary woo-button-m woo-button-round woo-dialog-btn')[0].click();
      console.log(true)
    }, 2000) 
      setTimeout(()=>{
          deleteMessage()
      }, 1000)
  }
}
// 执行(想要提速可以多执行几次)
deleteMessage()
```
复制粘贴在能够手动删除微博的网页端 F12的控制台中，（需要手动写入 允许粘贴）
